### 对 MILP：

即使变量都为整数，也会在搜索时（隐含地）求小数类型的 LP 下界，而对一个操作，不同的不等式刻画方法会对应不同高度的 LP 下界，LP 下界越接近最优化的取值（或满足解）时求解速度越快。

* 约束多=模型变重，LP 下界变紧；
* 约束少=模型变轻，LP 下界变松；

因此，一味追求不等式数量少是低效的，应该在（LP 下界，不等式数量）之间找到平衡。

也就是说，使用贪心算法讲 Sbox 的约束不等式缩减到最少并非效率最高的办法，引入一些约束来缩紧 LP 边界可能更有效（下面例子来自 chatgpt）

### 对 CP：

CP 的特点是可以很快的找到解，但需要很长时间验证找到的解为最优解。

适用于可将复杂非线性（SBox）转化为查表的情况。

使模型高效的技巧：
* 使用全局约束（Minizinc提供的，exists，max...）
* 缩紧变量的值域空间，可以引入一些冗余约束（比如概率上下限，Sbox活跃下限）
* 多使用 <-> （蕴含关系），少使用 -> （对决策变量空间松弛的约束）

一种高级用法：固定最优解，枚举所有满足该解的决策变量（间allsolution）。
